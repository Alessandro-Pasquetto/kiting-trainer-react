
# Kiting Trainer

A web-based training tool designed to practice and improve kiting mechanics through a simulated arena.

## Features

- **Player Movement:** Move the player by right-clicking on the arena, with configurable movement speed.
- **Attack Range:** Visualize the attack range using a circular indicator.
- **Attack Mechanics:** Practice attacking by clicking when the enemy is within range.
- **Configurable Settings:** Adjust movement speed, attack range and attack speed.
- **Statistics:** Track attack speed, attack intervals and click accuracy, including average values.

## Controls

| Input | Action |
|---|---|
| Right Click | Move the player |
| Left Click | Attack |
| A | Show attack range |
| S | Stop player movement |
